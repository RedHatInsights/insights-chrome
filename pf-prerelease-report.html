Heads-up for the skill runbook: The ERESOLVE guidance ("add conflicting package to overrides") did not resolve the peer dep conflict in this run. Both flat and nested overrides triggered the same error because npm 8's ERESOLVE fires even when an override violates a peer dep spec. --legacy-peer-deps was required as a fallback. The runbook should document this as a known npm 8 behavior when prerelease version strings don't satisfy upstream peer dep semver ranges.
